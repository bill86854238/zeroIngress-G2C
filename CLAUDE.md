# Project Instructions

## README sync rule

This project has two README versions:
- `README.md` — Traditional Chinese
- `README.en.md` — English

Whenever either README is updated, **always update both versions** so they stay in sync. Do not leave one version outdated.

## Localisation

- `README.md`: write in **Traditional Chinese** using natural, native phrasing (台灣繁體中文慣用語)
- `README.en.md`: write in **natural English**, not translated-sounding text

## Git

After completing any documentation or code change, ask the user if they want to push — or push immediately if they say so.
